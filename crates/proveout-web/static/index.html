Profile a machine or a post

Before you trust a check, check the profile it uses. Proveout tests the profile's numbers, compares your post with the machine, scans the post for codes that change offsets or call programs, and runs a program you know is good. A known-good program that fails means the profile is wrong. Fix it before checking new programs. None of this is a guarantee.
