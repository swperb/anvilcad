# Commercial pledge

AnvilCAD is free and open source, and it will stay that way. This page explains how the
project may earn money without taking anything away from people who never pay.

## What stays free

- **The whole app.** AnvilCAD, its geometry kernels, its command-line tools (including
  `anvil-migrate` and `anvil-bulk`) and its scripting API stay licensed under MIT OR
  Apache-2.0, complete and free to download. There is no paid edition and no feature
  that exists only in a paid build.
- **Your data.** Nothing you need to open, edit, migrate or export your own files will
  ever sit behind a payment, an account or a licence key. AnvilCAD's own file formats
  stay open: versioned JSON that any program can read, with the code that reads and
  writes it in this repository.
- **Your machine.** The desktop app needs no account and no licence server. It has no
  advertising and sends no telemetry.
- **The licence.** AnvilCAD will not move to a "source-available" licence such as the
  Business Source License. Code already released under MIT OR Apache-2.0 stays available
  under those terms.

## What may cost money

Any paid offering will be a service that people can choose to pay for: time, expertise or
servers. It will never be access to the software.

- **Help moving to AnvilCAD**, such as converting a company's archive of parts.
- **Support contracts** for organisations that want guaranteed response times.
- **A hosted server** for features that need one, run on someone's behalf. If AnvilCAD
  offers hosting, the same server will be free to run yourself, every record will be
  exportable in open formats, and moving from the hosted service to your own server will
  take one step.
- **Proveout**, the separate CNC program checker in this repository, has paid plans for
  its AI reviews, because each review costs money to run. Its deterministic checks need
  no plan.
- **Sponsorship** through [GitHub Sponsors](https://github.com/sponsors/swperb).

## How paid work affects the project

- Fixes and features built during paid work go into the open repository.
- A support contract buys a faster, guaranteed response. Nobody else's issues are
  answered any later because of it.
- Contributions are accepted under the Developer Certificate of Origin and the project's
  licence. No contributor licence agreement is needed, and none will be added to relicense
  contributors' work.

If anything the project does ever seems to break this pledge, open an issue and point to
this page.
