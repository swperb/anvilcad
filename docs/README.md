# AnvilCAD site

This is the AnvilCAD landing page: plain static HTML and CSS with no framework, no JavaScript and no build step. To preview it, open `index.html` directly in a browser, or serve the folder locally with `python3 -m http.server 8000` from inside `docs/` and visit http://localhost:8000. GitHub Pages publishes this folder from the `main` branch at https://swperb.github.io/anvilcad/. `screenshot.png` is the README image and is not used by the page.
