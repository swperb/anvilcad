# AnvilCAD site

This is the AnvilCAD landing page: plain static HTML and CSS with no framework, no JavaScript and no build step. To preview it, open `index.html` directly in a browser, or serve the folder locally with `python3 -m http.server 8000` from inside `site/` and visit http://localhost:8000. It can be published as-is on GitHub Pages by pointing Pages at this folder.
